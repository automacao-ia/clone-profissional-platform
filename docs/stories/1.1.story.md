# Story E1.1 — Registro e Login com Email e Senha

**Epic:** E1 — Autenticação e Gestão de Conta
**Status:** InProgress
**Agente:** @dev (Dex)
**Sprint:** 1

---

## Descrição

Como usuário, quero me registrar e fazer login na plataforma com email e senha para acessar meu dashboard de clones.

## Acceptance Criteria

- [ ] Página `/register` com campos: nome, email, senha (min 8 chars), confirmação de senha
- [ ] Página `/login` com campos: email e senha
- [ ] Registro cria usuário no Supabase Auth + linha na tabela `profiles`
- [ ] Login gera sessão JWT gerenciada pelo Supabase
- [ ] Rota `/dashboard` protegida — redireciona para `/login` se não autenticado
- [ ] Mensagens de erro em PT-BR (email já existe, senha fraca, credenciais inválidas)
- [ ] Link "Esqueci minha senha" na página de login (envia email de reset)
